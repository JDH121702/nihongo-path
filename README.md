# Nihongo Path

A research-backed Japanese site with **two mastery paths from zero to fluency**.

1. **Speaking & Listening** — Real dialogues, pattern chunks, cultural notes, shadowing. Romaji / hiragana / katakana only.
2. **Reading Kanji** — Radical-based recognition + graded stories and news-style reading. No handwriting drills.

## The fluency contract

This is not a weekend course. The path is staged for roughly **2,200 speaking hours** and **1,800 reading hours** of designed study (about 45 minutes a day: new lesson + due reviews).

| Stage | Hours | You can… |
| --- | --- | --- |
| Foundation | 0–80 | First conversations, kana automatic, first stories |
| Survival | 80–250 | Function in Japan: food, trains, shops, help |
| Daily Life | 250–500 | Friends, plans, casual/polite switch |
| Intermediate | 500–1,000 | Work, health, relationships, stories |
| Advanced | 1,000–1,800 | Keigo, media, bureaucracy, news reading |
| Fluent | 1,800–2,500+ | Implication, humor, adult print Japanese |

Method: comprehensible input at i+1, pattern-first chunks, retrieval + spaced repetition, early authentic reading, output after input.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Progress is saved in the browser by default. To deploy on **Cloudflare Workers** with **Google accounts** and cloud-synced progress, follow [DEPLOY.md](./DEPLOY.md).
